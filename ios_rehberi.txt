1. TERMINAL NASIL ACILIR? (WINDOWS & VS CODE)
--------------------------------------------------------------------

YONTEM A: VS Code Icinden Terminal Acma (En Pratik Yol)
1. VS Code programi acikken klavyeden `Ctrl + Shift + ` ` (Ctrl ile birlikte kesme/eğik tırnak işareti) tuslarina basin.
2. Veya ust menuden: "Terminal" -> "New Terminal" (Yeni Terminal) secenegine tiklayin.
3. Ekranin alt kisminda siyah/koyu bir komut satir paneli acilacaktir.

YONTEM B: Windows Komut Istemi (CMD) veya PowerShell
1. Klavyeden `Windows + R` tuslarina basin.
2. Acilan kutuya `cmd` veya `powershell` yazip Enter'a basin.
3. Proje klasorune gitmek icin su komutu yazin:
   cd C:\Users\guestt\Desktop\bymcloud


--------------------------------------------------------------------
2. ANDROID TEST CIKTISI ALMA (WINDOWS UZERINDEN)
--------------------------------------------------------------------
Terminali acip proje klasorundeyken su komutu calistirin:

   flutter build apk --release

Olusan dosya konumu:
   build\app\outputs\flutter-apk\app-release.apk

Bu .apk dosyasini telefonunuza gonderip dogrudan kurabilirsiniz.


--------------------------------------------------------------------
3. iOS CIKTISI VE YAYINLAMA ADIMLARI
--------------------------------------------------------------------

GEREKSINIMLER:
1. Apple Developer Hesabi (Yillik $99) -> developer.apple.com
2. Paket Adi (Bundle ID): com.bymcloud
3. Versiyon Ayari: pubspec.yaml icindeki "version: 1.1.3+113"
   (Her yeni iOS ciktisinda +113 sayisini arttirin, ornegin +114).


SECENEK 1: MAC BILGISAYAR ILE DERLEME
-------------------------------------
Projenizi Mac bilgisayara aktardiktan sonra Mac Terminalinde:

1. Paketleri yukleyin:
   flutter pub get
   cd ios
   pod install
   cd ..

2. Xcode Ayari:
   - ios/Runner.xcworkspace dosyasini Xcode ile acin.
   - Runner -> Signing & Capabilities kısmından Apple hesabınızı ve com.bymcloud secin.

3. Derleme Alin:
   flutter build ipa --release

4. TestFlight & App Store:
   Xcode menusunden Product -> Archive tıklayıp TestFlight'a yukleyin.

--------------------------------------------------------------------
4. TESTFLIGHT ILE TELEFONDA TEST ETME
--------------------------------------------------------------------
1. .ipa ciktisi App Store Connect'e yuklendikten sonra TestFlight sekmesinde gorunur.
2. iPhone telefonunuza App Store'dan "TestFlight" uygulamasini indirin.
3. E-posta adresinize gelen davet baglantisina tiklayarak uygulamayi kurun ve test edin.
